# Changelog

## 1.0.0 — 2026-11-21

- First release for Drupal 10.3+ and 11: `{avdeb-products}`, `{avdeb-product}` and `{avdeb-button}` tags
  in any text format (enabled in Basic HTML and Full HTML on install), an *AVDEB Products* block,
  settings page with connection status and "Refresh products now"; grid, carousel, list and spotlight
  layouts; single products as horizontal, hero or card; own cache bin with one-week stale fallback and
  request budget; render cache tags and max-age; `--avdeb-*` CSS tokens with zero-specificity styles.
